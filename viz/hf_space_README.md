# cuSHR DAG visualizer

Explore the Sanskrit Heritage Reader segmentation lattices: type a sentence
number (or original `sent_id`) and see the full DAG of candidate word-form
sequences, with an optional **gold-path highlight**. Ships a self-contained
demo database, so nothing is needed on the client side.

Built as part of the cuSHR project (GPU top-K lattice decoding for Sanskrit
word segmentation).
